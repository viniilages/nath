# Toquetti — site institucional

Site estático responsivo construído a partir dos materiais disponíveis no ZIP salvo do perfil @toquettiltda.

## Estrutura
- `index.html` — página completa
- `styles.css` — identidade visual, layout e responsividade
- `script.js` — pequenas interações e animações
- `assets/` — imagens derivadas do conteúdo salvo do Instagram

## Publicação
Pode ser publicado diretamente em Netlify, Vercel, GitHub Pages, Hostinger ou qualquer hospedagem que sirva arquivos estáticos.

## Observação
O HTML salvo pelo Instagram não trouxe o conteúdo textual completo do perfil porque a página é carregada dinamicamente. Por isso, a estrutura e os textos do site foram construídos usando o material visual efetivamente salvo no ZIP, sem inventar número de telefone, e-mail ou outros dados de contato que não apareceram nos arquivos.
